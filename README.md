# Cat's Tail Café ☕🐾

A cozy, fantasy-inspired café website: coffee, companions, and card games, wrapped in a warm Genshin Impact–style aesthetic (yes, it's set in Mondstadt).

**Live demo:** https://github.com/sama-abbasi/Cats-Tail-Cafe

This is a fan project, made for practicing front-end design and development. It is not a real business and it is not affiliated with or endorsed by HoYoverse.

## What's inside

A multi-page static site built with plain HTML, CSS, and vanilla JavaScript. No frameworks, no build tools.

- **Home**: hero section, auto-playing featured menu slider, TCG lounge, upcoming events, gallery, and a testimonials carousel
- **About**: the story behind the café and behind this website
- **Menu**, **TCG Lounge**, **Gallery**, **Reservation**, **Directions**: additional pages

## Features

- Automatic featured menu slider with looping, dot navigation, and pause on hover
- Testimonials carousel
- Smooth-scroll navigation for in-page links
- First-visit popup linking to the story page
- Custom paw-print cursor
- Responsive layout for desktop, tablet, and mobile

## Design

- Fonts: Cinzel for headings, Montserrat for buttons and navigation, Lato for body text
- Colors: warm cream, dark espresso, gold accents, and a deep wine hover color

## Running it locally

Open `index.html` in a browser, or serve the folder with any static server (for example the VS Code Live Server extension) so relative paths and fonts load properly.
